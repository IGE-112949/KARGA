# Karga — site (landing page)

Página estática (HTML + CSS + um pouco de JavaScript, sem build), adaptada do artifact "Karga — Landing Page".

- `index.html` — a página
- `main.js` — simulador de ganhos e animações
- `assets/` — imagem da tomada Shelly e ícone
- configuração da Vercel: `vercel.json` na raiz do repositório

Ver no PC: abrir `index.html` no browser, ou `npx serve apps/site`.

Deploy (Vercel): importar o repositório com **Root Directory = raiz (KARGA)**. O `vercel.json` da raiz já diz à Vercel para publicar só `apps/site`, sem instalar nem compilar nada.
